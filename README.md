# 🎂 Happy Birthday Papiya Mini Website 🎉  

A beautiful, interactive mini website built to celebrate my girlfriend Papiya’s special day ❤️.   
This project is made with **HTML, CSS, and JavaScript** and includes animations, memory photo boxes in 9:16 ratio, and heartfelt wishes.   

---

## 🚀 Live Demo  
👉 [Click here to view the site](https://kakaxiaeofficial.github.io/Abubakar_x_Papiya/last.html)

## 🎁 Features   
- 💌 Heartfelt birthday messages with smooth animations  
- 📸 Memory cards gallery featuring optimized 9:16 photo display  
- 🌟 Fully responsive design (works perfectly on mobile & desktop)  
- ✨ Easy to customize with your own photos and names

## 🛠️ Tech Stack

- **CSS3** (with custom animations and gradients)  
- **JavaScript**
